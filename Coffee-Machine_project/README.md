# Coffee Machine

A simple Coffee Machine simulation built using Python. This program focuses on implementing the complete program logic using fundamental Python concepts, without using Object-Oriented Programming (OOP).

## About the Project

The program simulates the basic operations of a coffee machine. Users can select a coffee, make a payment, and receive their coffee if the required resources and payment are available.

The program was developed to strengthen my understanding of Python fundamentals and problem-solving through procedural programming.

## Features

* Displays available coffee options
* Allows users to select a coffee
* Checks whether sufficient ingredients are available
* Processes the user's payment
* Calculates the change
* Updates the available resources after making a coffee
* Displays the current machine report
* Handles invalid selections and insufficient resources
* Allows the machine to be turned off

## Coffee Options

The machine supports different coffee options, each requiring specific ingredients and having a different price.
